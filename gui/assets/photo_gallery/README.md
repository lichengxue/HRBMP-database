# Photo Gallery Assets

Save reviewed photo-gallery images in this folder for future use in the GUI.

The `web/` subfolder contains generated JPEG copies used by the published GUI.
Keep original photos in the category folders, then regenerate or update the
matching web copies when new HEIC or large source images are added.

Recommended file naming:

- `YYYY-MM-DD_region_station_subject_credit.jpg`
- `YYYY-MM-DD_species_life-stage_credit.png`

Suggested metadata to track separately:

- Photo date
- HRBMP region or station
- Species, life stage, gear, habitat, or survey event
- Photographer or source credit
- Public/restricted release status

Do not place confidential, restricted, or unapproved photos in this public GUI
folder unless they are cleared for release.
