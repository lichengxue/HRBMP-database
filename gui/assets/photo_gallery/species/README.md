# Representative fish photographs

This collection contains exactly one reviewed photograph for each of 20 species
with a recorded archive view code `01` (left-side view). Photographs were chosen
for an unobstructed specimen, a complete outline, visibility of diagnostic
features, and focus, from locally available copies of the uploaded archive.
The Atlantic cutlassfish photograph was supplied by the user in response to the
request for the catalog filename recorded in the manifest.

Species labels follow the existing catalog identifications; visual screening
selects photographic quality and is not an independent taxonomic validation.
The Tessellated Darter display name corrects a spelling error in the catalog's
common-name text without changing its taxon code or specimen association.

The sources are preserved outside this repository. These web JPEG copies retain
the full frame, apply the source's EXIF display transform, and resize to a maximum
of 1600 pixels on the longest edge. They are not cropped, mirrored, retouched,
recolored, or generated. Each copy has EXIF Orientation 1 and omits source GPS
and unrelated camera metadata. No pixel scale measurements should be inferred
from the resized files alone.

`manifest.json` records the catalog ID, archive filename, taxon code, specimen
view, original and derivative checksums, and derivative dimensions. It contains
no local source paths or credentials. The user authorized these representative
photographs for the public gallery; bulk archive access remains unchanged.

As checked November 23, 2026, the live public catalog contained 5,708 available
fish photographs representing 23 species. Three flatfish species (hogchoker,
windowpane, winter flounder) had no recorded view 01, and the user explicitly
requested that other views not be substituted. They are therefore omitted
from this representative gallery. This is an audit snapshot, not a live counter.

## Species names and biological descriptions

Each card displays its archive common name, an italic scientific name, a short
original summary of general species biology, and direct reference links. The
page header has no subtitle. Descriptions do not claim that the pictured
preserved specimen demonstrates adult coloration or every described trait.

The adjacent manifest records the scientific name, description, source URLs,
and review date for all 20 species. Accounts were checked against the Chesapeake
Bay Program field guide, NOAA Fisheries, Connecticut DEEP, Texas Parks and
Wildlife, and FishBase. These are biological references; the gallery photographs
remain the user-authorized HRBMP images, not images copied from those portals.

Spottail Shiner uses FishBase's current name *Hudsonius hudsonius*. The name
*Notropis hudsonius*, retained by some agency accounts and older datasets, is
recorded as an alias. The archive taxon code and specimen association are
unchanged. Spotted Hake uses *Urophycis regia*, also called Spotted Codling in
FishBase. Biological prose is paraphrased, and changing stock-status claims,
regulations, and maximum-size records are deliberately omitted.
