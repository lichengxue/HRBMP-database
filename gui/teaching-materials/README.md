# Supplementary teaching slides

Authorized PowerPoint copies and PDF companions for the HRBMP education portal:

- Survey Design Background: 22 slides.
- Hudson River Survey Design Challenge: 19 slides.

The PowerPoint files retain the supplied slides and image-credit notes. PDFs
were exported locally with Microsoft PowerPoint, preserving slide layouts.
Cover images were rendered from their first PDF pages using Poppler.
`manifest.json` records source filenames, sizes and SHA-256 hashes. See
`docs/education-materials.md` at the repository root for regeneration steps.
