Program Description

HRBMP Program Overview

Purpose

This GUI organizes HRBMP information around monitoring stations, sampling events, biological observations, environmental observations, and source metadata. The portal keeps the workflow transparent for scientific users while the database structure is still being refined.

Data Workflow

  1. Load validated source tables into SQLite.
  2. Export analysis-ready JSON summaries for the static GUI.
  3. Review coverage by station, time period, taxonomic group, and data type.
  4. Update records with reviewed HRBMP data and documentation.
