# GUI Notes

The GUI is currently a **static front-end prototype** using only:

- HTML
- CSS
- JavaScript (no frameworks)

It reads `gui/data/example_summary.json` and displays:
- key counts
- station table
- annual abundance summary
- taxa totals
- environmental means

## Current limitations

- No live database connection.
- No backend/API.
- No authentication.
- No advanced charting library.

## Future options

- Host directly with GitHub Pages for easy sharing.
- Add lightweight charting and map visualization.
- Connect to an API/backend if dynamic querying is needed.
